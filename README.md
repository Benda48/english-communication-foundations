# English Communication Foundations
## Professional Complete Curriculum — Professional Edition

**A comprehensive 8-week intensive English communication program for French-speaking beginners (A1 CECRL level)**

---

## 📋 Program Overview

- **Duration:** 8 weeks | 32 sessions | 32 hours
- **Target Audience:** Francophone beginners (students, young professionals, entrepreneurs, job seekers)
- **Class Size:** 30 learners per class
- **Target Level:** A1 Functional CECRL
- **Approach:** CLT (Communicative Language Teaching) + TBL (Task-Based Learning) + Speech Priority

---

## 🎯 Learning Outcomes

By the end of 8 weeks, learners will be able to:

1. Introduce themselves (name, nationality, profession, age)
2. Give and request personal information
3. Describe family and relationships
4. Discuss daily routine using present simple
5. Order at a restaurant or café
6. Make simple purchases and ask prices
7. Ask for and give directions
8. Talk about hobbies, work, and projects using basic formulas

## 🎓 Pedagogical Approach

### Core Philosophy
**"You learn to speak by speaking."** 

Grammar is not an end in itself—it's a tool for communication. Every session is designed so learners:
- Start speaking from the first minutes
- Make mistakes safely
- Correct progressively
- Build confidence through immediate application

### Teaching Methods
- **CLT (Communicative Language Teaching):** Real communication at the core
- **TBL (Task-Based Learning):** Learning structured around communicative tasks
- **PPP Model:** Presentation → Controlled Practice → Free Production
- **Andragogy:** Adult learning principles with focus on learner autonomy

### Key Principles
✓ Speech is prioritized over writing  
✓ Error is a learning tool, not a fault  
✓ Each hour produces something immediately usable  
✓ Pleasure and motivation are learning conditions, not accessories

## 🗣️ Pronunciation Program

### Specific Challenges for French Speakers
- **/θ/ and /ð/ sounds** → Inexistent in French (often replaced by /s/ or /z/)
- **/h/ aspiration** → French H is silent; English H is aspirated
- **/w/ vs /v/ confusion** → Common error: "vater" instead of "water"
- **Word stress** → French is syllabic; English is stress-timed
- **Final consonants** → French doesn't pronounce final consonants

**Solution:** Specific drills provided each week with mirror exercises and minimal pairs.

## ✅ Assessment Framework

### Three-Tier Evaluation
1. **Diagnostic Assessment (Lesson 1)**
   - Identify actual level and adapt teaching
   
2. **Mid-Course Assessment (Lesson 16 — End Week 4)**
   - Formative evaluation of Sessions 1-4
   - 30-minute test covering all 4 skills
   
3. **Final Assessment (Lesson 32 — End Week 8)**
   - Summative evaluation validating A1 functional level
   - 45-minute comprehensive exam

### Speaking Rubrics
- Fluency | Pronunciation | Vocabulary | Grammar Accuracy | Comprehension | Interaction
- 6 criteria × 5-point scale = Detailed feedback for each learner

## 👥 Class Management (30 Learners)

### Group Rotation System
- **Color-card system:** Assign each learner a color (5 colors, 6 learners each)
- **Flexible configurations:** Pairs, trios, groups of 4-5, half-class activities
- **Maximum engagement:** Ensure every learner speaks at least once per session

---

## 📱 Digital Engagement: WhatsApp English Club

### Weekly Challenge Structure
- **Monday:** Vocabulary challenge (post selfie + 3 sentences)
- **Tuesday:** Listening challenge (watch YouTube, note new words)
- **Wednesday:** Speaking challenge (record 20-second introduction)
- **Thursday:** Word of the day (use in a sentence)
- **Friday:** Weekend mission (speak English with someone outside class)

---

## 💡 For Instructors

### Best Practices
- Use English from the first minute of class
- Vary activities every 8-12 minutes
- Have a backup activity prepared
- Always finish on time (adult learners have other commitments)
- Celebrate effort, not just perfection

### Typical Preparation Time
- **First week:** 2-3 hours (familiarize with structure)
- **Weeks 2-8:** 30 minutes per week (material review + WhatsApp prep)
